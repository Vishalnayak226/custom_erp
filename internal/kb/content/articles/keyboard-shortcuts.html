Keyboard shortcuts and quick codes #

Press ? on any screen (when you are not typing) to see the keys and codes, with Report numbers (every report's number), Guide (this page) and Print (a shortcut card to keep by the keyboard). On a Mac, use ⌘ wherever this page says Ctrl.

The search box: Ctrl+K #

Ctrl+K (or /) puts you in the search box at the top. Type, then press Enter to open the first result, or use ↑ ↓ to choose. Esc closes it.

You typeWhat opens
A name, e.g. purchaseMatching screens, record lists and reports
A code, e.g. POThat screen (codes are listed below)
A code and +, e.g. PO+A new record on that screen
A code and a number, e.g. PO 42Document number 42 of that kind. If several stores have a 42, you pick one
A report number, e.g. R1001That report
A full document number, e.g. PO/HO/26-27/00103That document, shown in its record list
Nothing (just Ctrl+K)Your Favourites, My work counts and Recent screens

A code, number or document opens only if your role can open it from the menu. Each result shows its code or report number on the right, so you learn them as you go.

Scan to open: with the cursor outside any field, scan the barcode printed on a document and it opens.

Report numbers #

Every report has a fixed number: R, then the area digit, then three digits. Sales Register is R1001. A number never changes and is never reused, and it is the same for every company, so you can say "run R3004" to anyone.

The number shows beside the report's name in the Reports menu, on the report page, and in the name of an exported file. To find a number, press ? and choose Report numbers, or see the Report catalog.

Favourites and recent #

  • ☆ beside a screen's title adds it to your favourites (★). Click again to remove it. Favourites appear first when you press Ctrl+K, on any computer you sign in to.
  • Recent shows the last 10 screens, reports and documents you opened in this browser.

Less typing #

  • Copy a record: the Copy icon on a record list row, Copy on a Purchase Order in the PO list, or Copy in the after-save bar. The number, status and dates are not copied. Check it and save.
  • Your last choice comes back: a drop-down for store, location, warehouse, counter, salesman, cost centre or payment mode starts on what you last picked on that screen, in this browser. It is highlighted so you can see it was filled for you.
  • Unsaved work is kept: if the tab closes while a New form has details in it, the form offers Restore or Discard next time. Only the form's own boxes are kept, not the rows of a line table.
  • Saved views: on a record list, type a search in the box above the table, then pick Save this search as a view… in the views drop-down beside it. Pick the view later to run the same search. Views follow you to any computer.
  • Ticked rows: tick rows on a record list (Space ticks the row you are on). A bar offers Export (a CSV of the ticked rows), Submit for approval (where the list has that action) and Delete; Submit and Delete do up to 40 rows a run.
  • Approvals: tick rows and click Approve ticked or Reject ticked. Each is decided exactly as if you had clicked its own button. A password reset is always decided on its own.
