Find help for your task #

Choose Help for this screen in the application header to open related instructions. Use Knowledge Center in the navigation to browse all topics. Screen coverage is still being completed; a general topic is not evidence that every operation on that screen is documented.

Search or browse #

Type at least two characters in Search help.... Use the task name, a record name or the error code shown by the application. Choose a result to read the topic, or use the grouped topic links in the sidebar. The help search searches instructions, not your business records.

Follow topic headings in reading order and check the prerequisites before performing an action. The role journeys provide a starting point for a new role. For a failed action, start with Reading an error code.

You can navigate links and the search box with the keyboard. If a control cannot be reached or its meaning is unclear with assistive technology, report the task, browser/device and the control that blocked you.

If the instructions do not match #

Stop before an irreversible business action. Give support the screen/task, article title, application version, and error/correlation ID if one is shown. Describe what you expected and what appeared. Do not send passwords, session tokens or unrelated customer records. A help article does not grant permission or override your organization's approved procedure.
