Error code reference #

Every refusal in this application carries a code. There are 580 of them, across 75 areas. This page is produced from the running catalog, so it cannot describe a code the application does not have, or miss one it does.

Search is usually faster than scrolling: type the code into the search box at the top of the sidebar. If you have not met a code yet and want to know how to read the dialog it appears in, start with Reading an error code.

Note

A code with an HTTP status of 500 or above is an internal failure, not something you did. The detail line is deliberately withheld in that case - give your administrator the correlation id shown in the dialog instead.

The list runs over 2 pages. The contents below cover every area and open the right page.
