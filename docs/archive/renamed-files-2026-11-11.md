# Renamed files, 2026-11-11

the stage that built it. On 2026-11-11 (items 103.3 and 160.1) the files below were renamed to follow it.
Tracker items, ledger sections and release reports written before that day still use the old names:
look them up here. Paths are from the repository root.

## Migrations

for example `db/migrations_stage47_7_audit_evidence.sql` is now
`db/migrations/migrations_stage47_7_audit_evidence.sql`. The runner reads them by bare name, so no
database re-applies anything.
