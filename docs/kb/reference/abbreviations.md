# Abbreviations

Short forms appear on screens where space is tight and in error messages where
precision matters more than length. This is all of them.

For concepts rather than initials, see the [Glossary](glossary.md).

## Documents and operations

| Short form | Stands for | What it is |
|---|---|---|
| **ASN** | Advance Shipment Notice | A supplier's notice of what they have dispatched. Not stock - a promise you can plan a dock around |
| **AWB** | Air Waybill | The courier's tracking number for a shipment |
| **BOM** | Bill of Materials | What a manufactured item is made of |
| **GRN** | Goods Receipt Note | Proof that ordered stock actually arrived. Posting it is what creates stock |
| **LPN** | Licence Plate Number | The id of a handling unit - a carton or pallet treated as one thing |
| **PO** | Purchase Order | What you have ordered from a supplier |
| **POS** | Point of Sale | The till screen |
| **RFQ** | Request for Quotation | Asking suppliers to quote before you order. Never mandatory - a purchase order does not require one |
| **SO** | Sales Order | A customer's order |
| **SKU** | Stock Keeping Unit | The unique code identifying one specific product |
| **UOM** | Unit of Measure | Each, kilogram, box - how a quantity is counted |

## Tax and compliance

| Short form | Stands for | What it is |
|---|---|---|
| **GST** | Goods and Services Tax | The sales tax, calculated automatically |
| **GSTIN** | GST Identification Number | A business's tax registration. Its first two digits are the state code, which is how intra-state versus inter-state is decided |
| **HSN** | Harmonised System of Nomenclature | The tariff code classifying a product for tax. Required on every item, whatever its rate |
| **GSTR-1** | GST Return, form 1 | The outward-supplies return. Nil and exempt supplies are reported HSN-wise, which is why HSN is required even at 0% |
| **IFSC** | Indian Financial System Code | Identifies a bank branch |
| **LUT** | Letter of Undertaking | Lets exports be made without paying tax up front |
| **PAN** | Permanent Account Number | An Indian tax identity |
| **SEZ** | Special Economic Zone | Supplies to one are zero-rated |
| **TDS** | Tax Deducted at Source | Tax withheld from a payment |

## Money

| Short form | Stands for | What it is |
|---|---|---|
| **AP** | Accounts Payable | What you owe suppliers |
| **AR** | Accounts Receivable | What customers owe you |
| **COD** | Cash on Delivery | Paid when the goods arrive |
| **FX** | Foreign Exchange | Anything involving a currency other than your own |
| **GL** | General Ledger | The accounting record itself |
| **MRP** | Maximum Retail Price | The printed ceiling price |
| **P&L** | Profit and Loss | The income statement |

## People, security and systems

| Short form | Stands for | What it is |
|---|---|---|
| **2FA / MFA** | Two-Factor / Multi-Factor Authentication | A second sign-in check beyond the password |
| **API** | Application Programming Interface | How another system talks to this one |
| **CSV** | Comma-Separated Values | The spreadsheet format used by every bulk import and export |
| **HR / HRM** | Human Resources / Management | The people module |
| **JWT** | JSON Web Token | The digital ID card your browser presents on each request |
| **RBAC** | Role-Based Access Control | Permission follows the role, not the person |
| **SLA** | Service Level Agreement | The time a task is expected to take. Exceeding it is an SLA breach |
| **SSO** | Single Sign-On | Signing in through an identity provider your business already uses |
| **TOTP** | Time-based One-Time Password | The six-digit code an authenticator app shows |
| **UAT** | User Acceptance Testing | Trying it properly before going live |

## Warehouse and logistics

| Short form | Stands for | What it is |
|---|---|---|
| **ATS** | Available to Sell | Physical stock minus what is reserved |
| **DC** | Distribution Centre | A warehouse that supplies stores rather than customers |
| **FEFO** | First Expired, First Out | Picking the earliest expiry first |
| **FIFO** | First In, First Out | Picking the oldest stock first |
| **OMS** | Order Management System | The screen that follows an order end to end |
| **PIM** | Product Information Management | The product content and readiness layer |
| **WMS** | Warehouse Management System | The bin, pick, pack and count screens |
